# Borç Takip

Kredi, ödeme takvimi, gelir-gider dengesi ve borç kapatma planı. Build yok, saf HTML/JS.

## Kurulum
1. Bu klasörü **private** bir GitHub reposuna yükle.
2. Vercel → Add New Project → repoyu seç → Framework: **Other** → Deploy. (Build komutu gerekmez.)
3. Telefonda siteyi aç → Paylaş → **Ana Ekrana Ekle**.
4. İlk açılışta **Dosyadan yükle** → `verilerim.json` (repoya koyma, telefona at).
5. Ayarlar (⚙︎) → PIN koy.

## Gizlilik
Hiçbir veri sunucuya gitmez; her şey telefonun tarayıcısında (localStorage) durur.
Kod public olsa bile kredilerin görünmez. Ara ara Ayarlar → Yedeği indir.
